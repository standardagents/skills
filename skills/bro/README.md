# bro

Snap a verbose agent into concise mode. Use when you get a wall of text and
what you needed was the answer.

```bash
npx skills add standardagents/skills@bro
```

## Usage

Invoke as `/bro` after a word-vomit response — the agent restates it
concisely — or before a question to get a tight answer in the first place.
Rules stay active for the rest of the session: lead with the answer,
technical English, short sentences, no hedging, no recap endings.
